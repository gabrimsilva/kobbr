# Arquivos de Som para Notificações

Esta pasta deve conter os arquivos de áudio para as notificações de novos pedidos.

## Arquivos necessários:

1. **ding1.mp3** - Ding Clássico
2. **ding2.mp3** - Ding Moderno  
3. **ding3.mp3** - Ding Suave

## Formato recomendado:
- **Formato:** MP3
- **Duração:** 1-3 segundos
- **Qualidade:** 128kbps ou superior
- **Volume:** Normalizado (não muito alto)

## Como adicionar:
1. Renomeie seus arquivos `ding.mpeg` para `ding1.mp3`, `ding2.mp3`, `ding3.mp3`
2. Coloque os arquivos nesta pasta (`public/sounds/`)
3. Os sons estarão disponíveis nas configurações do sistema

## Teste:
Após adicionar os arquivos, vá em **Configurações > Notificações Sonoras** para testar e selecionar o som desejado.
