🎁 SISTEMA DE DESCONTOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Adicionado suporte completo para descontos manuais em:
  ✓ Pedidos (delivery)
  ✓ Comandas (PDV)
  ✓ Histórico de pedidos
  ✓ Histórico de comandas
  ✓ Histórico geral

Novos Campos:
  • desconto (NUMERIC) - Valor do desconto
  • tipo_desconto (TEXT) - 'valor' ou 'percentual'

Exemplos:
  → Desconto de R$ 10,00: desconto=10, tipo_desconto='valor'
  → Desconto de 15%: desconto=15, tipo_desconto='percentual'

💳 PAGAMENTO DIVIDIDO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Adicionado suporte para dividir pagamento entre duas formas diferentes:
  ✓ PIX + Dinheiro
  ✓ Débito + Crédito
  ✓ Qualquer combinação

Novos Campos:
  • forma_pagamento_dividido (BOOLEAN)
  • pagamento_1_tipo (TEXT)
  • pagamento_1_valor (NUMERIC)
  • pagamento_2_tipo (TEXT)
  • pagamento_2_valor (NUMERIC)

Exemplo:
  → R$ 50 em PIX + R$ 30 em Dinheiro = Total R$ 80

┌──────────────────────────────────────────────────────────────────────────────┐
│ 💡 EXEMPLOS DE USO                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

1. Aplicar desconto de R$ 10:
   UPDATE pedidos 
   SET desconto = 10, tipo_desconto = 'valor'
   WHERE pedido_id = 'abc123';

2. Aplicar desconto de 15%:
   UPDATE pedidos 
   SET desconto = 15, tipo_desconto = 'percentual'
   WHERE pedido_id = 'abc123';

3. Pagamento dividido (R$ 50 PIX + R$ 30 Dinheiro):
   UPDATE pedidos 
   SET 
     forma_pagamento_dividido = true,
     pagamento_1_tipo = 'PIX',
     pagamento_1_valor = 50.00,
     pagamento_2_tipo = 'Dinheiro',
     pagamento_2_valor = 30.00
   WHERE pedido_id = 'abc123';

4. Consultar pedidos com desconto:
   SELECT codigo_pedido, cliente_nome, subtotal, desconto, tipo_desconto, total
   FROM pedidos
   WHERE desconto > 0
   ORDER BY criado_em DESC;

5. Consultar pedidos com pagamento dividido:
   SELECT codigo_pedido, total,
          pagamento_1_tipo, pagamento_1_valor,
          pagamento_2_tipo, pagamento_2_valor
   FROM pedidos
   WHERE forma_pagamento_dividido = true;
