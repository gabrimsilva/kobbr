## ❓ Perguntas Frequentes

### P: Por que o PDV foi simplificado?
**R**: Para reduzir complexidade e focar em funcionalidades essenciais. Consulte `ANALISE_FUNCIONALIDADES_REMOVIDAS.md` (Seção 1.1)

### P: Posso reativar desconto no PDV?
**R**: Sim, mas não é recomendado. Consulte `RECOMENDACOES_ACAO.md` (Seção 3.1)

### P: Quais componentes posso remover?
**R**: Nenhum arquivo deve ser removido. Apenas remova imports não utilizados. Consulte `COMPONENTES_OBSOLETOS_DETALHES.md`

### P: Como adicionar nova funcionalidade?
**R**: Siga o checklist em `RECOMENDACOES_ACAO.md` (Seção 6)

### P: Qual é o impacto de remover imports?
**R**: Reduz bundle em ~5KB. Consulte `RECOMENDACOES_ACAO.md` (Seção 1.1)

### P: Como os 3 fluxos diferem?
**R**: Consulte a matriz em `SUMARIO_VISUAL.md` (Seção "Matriz de Funcionalidades")

### P: Onde está o código de desconto?
**R**: `src/utils/descontoCalculation.ts`. Consulte `INDICE_REFERENCIA_RAPIDA.md`

### P: Como validar desconto?
**R**: `src/utils/descontoValidation.ts`. Consulte `CHECKLIST_CAMPOS_PAGAMENTO.md`

### P: Qual é o plano de ação?
**R**: Consulte `RECOMENDACOES_ACAO.md` (Seção 6)

### P: Quanto tempo levará implementar?
**R**: ~17 horas. Consulte `RECOMENDACOES_ACAO.md` (Seção 8)

## 📖 Glossário

### Termos Utilizados

| Termo | Definição |
|-------|-----------|
| **PDV** | Ponto de Venda - Vendas no balcão (simplificado) |
| **Comandas** | Vendas em mesas (intermediário) |
| **Delivery** | Vendas online (completo) |
| **Desconto Manual** | Desconto aplicado manualmente pelo operador |
| **Pagamento Dividido** | Pagamento dividido entre 2 formas diferentes |
| **Taxa Extra KM** | Taxa adicional por quilômetro de distância |
| **Split Payment** | Sinônimo de Pagamento Dividido |
| **Componente Obsoleto** | Componente não utilizado em um fluxo específico |
| **Hook** | Função React para lógica reutilizável |
| **Utilitário** | Função JavaScript pura para cálculos/validações |
| **Constraint** | Regra de validação no banco de dados |
| **Lazy Loading** | Carregamento sob demanda |
| **Memoização** | Otimização para evitar re-renders |
